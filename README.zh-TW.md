# SoftFolders

[English](README.md) | **繁體中文（臺灣）**

輕量的 Windows 原生桌面擴充元件，讓你像使用手機資料夾一樣，將多個應用程式捷徑整理成「軟體夾」。

![軟體夾預覽範例](docs/preview.png)

## 功能

- 桌面項目由檔案總管管理，可以和其他圖示一起排列、框選及移動。
- 固定 **3 × 3 九宮格預覽**，從左上角開始，由左至右、由上至下填入，最多顯示九個圖示。
- 統一圖示的可見尺寸與位置，保留透明背景。
- 擴充元件啟用時，按一下桌面的軟體夾即可展開。
- 以透明的 **10 欄 × 6 列**版面顯示內容，滑鼠移過圖示時不會產生矩形背景，也不會將展開視窗設為最上層。
- 展開前顯示桌面，收合後還原原先隱藏的視窗。
- 按兩下啟動應用程式、拖曳調整位置、按 Esc 或點選空白處收合。
- 拖曳捷徑加入群組時，不會自動展開，也不會移動原始檔案。
- 使用系統字型，並提供文字顏色選項。

本專案使用 C++／Win32／COM，不需要 .NET 或 Electron，也不需要讓設定工具持續執行。擴充元件仍會使用檔案總管的部分記憶體；展開時會額外配置繪圖資源。

## 安裝

支援 Windows 10／11 x64。

1. 從[發布頁面](https://github.com/Enchore/SoftFolders/releases/latest)下載 **SoftFolders-Windows-x64.zip**。
2. 解壓縮到準備長期保留的資料夾。
3. 執行 `SoftFoldersSetup.exe`，選擇「**安裝／更新擴充元件**」。
4. 使用設定工具建立軟體夾，或在桌面按滑鼠右鍵，選擇「新增 → 軟體夾」。Windows 11 的部分項目可能位於「顯示其他選項」中。
5. 將應用程式捷徑拖曳到軟體夾中。

請將 `SoftFoldersSetup.exe` 和 `SoftFoldersShell.dll` 保存在同一個資料夾。註冊範圍僅限目前使用者。登入時，設定工具會短暫執行，完成桌面事件處理的連結後便結束，不會持續常駐。

## 使用方式

按一下軟體夾即可展開；按兩下其中的圖示即可啟動應用程式。按滑鼠右鍵可新增或移除項目、切換頁面及調整文字顏色。每頁最多有 60 個位置。

軟體夾是儲存路徑與位置的 Unicode `.softfolder` 檔案。原始應用程式與捷徑會保留在原處。目前不支援在軟體夾內再放入另一個軟體夾。

## 解除安裝與更新

執行設定工具，選擇「**解除安裝擴充元件**」。群組資料與原始應用程式會保留。

已載入的 DLL 可能會留在檔案總管中，直到登出或正常重新啟動檔案總管。若要取代或刪除正在使用中的 DLL，請先解除安裝並登出。工具不會強制重新啟動檔案總管。

## 從原始碼建置

需要 Windows x64、Visual Studio 2022 或 Build Tools、「使用 C++ 的桌面開發」工作負載，以及 Windows SDK。

複製本存放庫後執行：

```powershell
.\build.cmd
```

腳本會透過 `vswhere` 尋找 Visual Studio，並將執行檔輸出至 `build/bin`。

## 驗證

```powershell
.\tests\test.cmd
```

測試會產生透明留白不同的範例圖示，檢查可見尺寸、透明度與預覽繪製結果，不會安裝擴充元件，也不會讀取個人桌面群組。

在一般 Windows 桌面環境中，也可以執行：

```powershell
.\build\bin\SoftFoldersSetup.exe --verify
.\build\bin\SoftFoldersSetup.exe --status
```

`--verify-desktop` 會暫時最小化並還原視窗，以驗證顯示桌面的流程。請先執行 `--verify` 產生測試資料，再於方便時手動執行這項檢查。

## 限制

本專案是實驗性的第三方檔案總管擴充元件，並非 Windows 內建功能。擴充元件的程式錯誤可能影響檔案總管的穩定性。多螢幕搭配不同 DPI 的情境尚未完成全面測試，執行檔目前也未經數位簽署。

存放庫不包含個人群組資料、診斷紀錄或第三方應用程式圖示。
